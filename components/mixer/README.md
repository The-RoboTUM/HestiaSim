# Mixer (mum8 with chute)

Kitchen mixer with a chute. In Isaac the bowl (1 kg) and the lid with the chute (0.35 kg) are rigid
bodies; the machine body is static.

| Version | File | Made by | What changed |
|---|---|---|---|
| v1 | `mum8_chute_v1.stl` / `.igs` (mm) | Hanzhang | first model, coarse (2k triangles) |
| **v2 (current)** | `mum8_chute_v2.stl` / `.igs` (mm), `mum8_chute_v2.usda` (m, for Isaac) | Mana | detailed model (50k triangles); USD with a static body and rigid bowl and lid |

- Origin and front: +x = bowl side (chute). The STL's bottom is at z = -233 mm; the USD lifts it by
  0.233 m so it stands on z = 0.
- Size: 457 x 293 x 339 mm (v2)
- Changes made here: none, as received. Renamed 2026-11-23 from `mum8_chute_hanzhang_v1_nov21` and
  `mum8_chute_mana_v1_nov22` (old naming, where each author counted their own versions).
