# Mixer (mum8 with chute)

Kitchen mixer with a chute. In Isaac the bowl (1 kg) and the lid with the chute (0.35 kg) are rigid
bodies; the machine body is static.

- Made by: v1 Hanzhang, v2 Mana (current). Renamed 2026-11-23 from `mum8_chute_hanzhang_v1_nov21` and
  `mum8_chute_mana_v1_nov22` (old naming, where each author counted their own versions).
- Current file: `mum8_chute_v2.stl` / `.igs` (mm), `mum8_chute_v2.usda` (m, for Isaac)
- Origin and front: +x = bowl side (chute). The STL's bottom is at z = -233 mm; the USD lifts it by
  0.233 m so it stands on z = 0.
- Size: 457 x 293 x 339 mm
- Changes made here: none, as received
- Older version: `mum8_chute_v1.stl` / `.igs` (coarser, 2k triangles);
  `mum8_v10_vs_original.png` is a comparison image
