# Aluprofil table

Lab table built from 80x80 aluminium profiles (slot 10), generated from measurements of the real table.

- Made by: Jeffrey (v1, measured on the real table 2026-11-22)
- Current file: `alu_table_v1.stl` (type `standard`, with diagonal braces) and
  `alu_table_no_brace_v1.stl` (type `no_brace`), both mm
- Origin and front: on the floor at the table centre; front edge at +y
- Size: 1800 x 960 x 1535 mm (table top at 680 mm)
- Changes made here: none; generated by `scripts/` (change a value there and regenerate)

## Details

| | |
|---|---|
| Frame | 1800 x 960 mm, 3 front legs (500 mm), 3 back uprights (1320 mm), 85 mm levelling feet |
| Top | 1800 x 840 mm, 7 planks of 120 x 15 mm, slots 10 mm every 30 mm (M6 T-nuts), flush with the front |
| Extras | back wall 1800 x 420 x 10 (R20), angle brackets, lower rails; type `standard` also has two 40x40 diagonal braces |
| Confirmed details | middle back upright has a levelling foot like the corners; the front rail is one 1640 mm piece over the middle front leg; lower rails on both sides; angle brackets on both sides of the middle back upright; bracket size 80 x 80 (accepted, not measured) |

Other files: `drawings/` (dimensioned drawing, settings sheet, PDF + PNG), `scripts/` (generator and
previews, see `scripts/README.md`).

Simulation uses metres: `scripts/make_table.py` writes `meshes/alu_table.obj` (m), which Isaac Lab
converts to `usd/alu_table.usd` (both generated, not committed).
